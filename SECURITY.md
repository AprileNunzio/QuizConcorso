# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of QuizConcorso seriously. If you believe you have found a security vulnerability, please do not open a public GitHub issue.

Please report vulnerabilities privately by opening a [GitHub Security Advisory](https://github.com/AprileNunzio/QuizConcorso/security/advisories/new) or contacting the maintainer directly:
- **Maintainer**: Aprile Nunzio (NunzioTech)
- **Repository**: [https://github.com/AprileNunzio/QuizConcorso](https://github.com/AprileNunzio/QuizConcorso)

You should receive an initial acknowledgment within 48 hours. Validated vulnerabilities will be addressed with high priority in a patched release.
